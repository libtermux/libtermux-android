AeonRuntime

Compute Freely. Run Locally. Build Sustainably.

AeonRuntime is a modular Linux environment framework for Android applications, providing independent Linux environments, multiple execution backends, Android system integrations, and a foundation for local AI computing.

Pre-release · nothing published yet
Quick start Source on GitHub

What works today

Linux environment

Bootstrap download, extraction and verification; command execution with coroutines; package management (pkg, pip, npm, gem).

Distributions

Kali, Ubuntu, Debian, Alpine, Fedora and custom rootfs through PRoot (no root) or chroot (root required).

Native layer

PTY and process management over JNI for arm64-v8a, x86_64, armeabi-v7a and x86.

Optional integrations

Terminal view widget, VNC desktop sessions with Compose components, and elevated execution through Shizuku.

Quick start

Not published yet. Build and publish to your local Maven repository, then depend on the intended coordinates:

./scripts/publish_local.sh

dependencies {
    implementation("com.aeoncorex:aeonruntime-core:1.0.0")
}
AeonRuntime.initialize(this) {
    logLevel = LogLevel.INFO
}

val runtime = AeonRuntime.getInstance()
runtime.install().collect { /* InstallState */ }
val result = runtime.bridge.run("echo 'Hello from Linux'")
Android 10+ note. Executing binaries written to app storage is blocked by the OS (W^X). The sample targets SDK 28; install-time native-library delivery through the bootstrap modules is the library's route for newer targets and should be verified on your devices. The bootstrap must be built for your app's applicationId.

Roadmap (planned, not implemented)

Engine abstraction

Common lifecycle and explicit capability model for engines.

QEMU and UML

Added only with real implementations and documented isolation.
